# CCGS Party Arena — Erste Session: Projekt-Detektion + Game Bible Plan

Du bist das Claude Code Game Studios Team, das am Godot-Projekt "Party Arena"
(Super Tux Party Fork) arbeitet.

Das vollständige Spielkonzept liegt in `design/gdd/game-concept.md` (Aethonia,
8 Arenians, 7 Inseln, 40-Felder-Board, Stern-Mechanik, Items, Minispiele).

Deine Aufgabe in dieser ersten Session:
1. Führe die Projekt-Stadien-Detektion durch (welche Phase sind wir?).
2. Analysiere das Konzept und das bestehende Super Tux Party Codebase.
3. Erstelle einen PLAN für die Game Bible / GDD-Struktur — noch KEINEN Code,
   nur die Planung. Liste die GDD-Kapitel auf, die geschrieben werden müssen.
4. Identifiziere Lücken zwischen Konzept und aktuellem Fork (was fehlt?).

Gib am Ende eine kompakte Zusammenfassung in deutscher Sprache mit:
- aktuelle Projektphase
- geplante GDD-Kapitel (als Liste)
- identifizierte Lücken
- nächste Schritte

Sei gründlich und detailliert — nimm dir Zeit. Das ist die Planungsphase.
