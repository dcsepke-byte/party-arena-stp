Der User ist der kreative Leiter / Product Owner des Indie-Projekts **Party Arena** (Fork von Super Tux Party, Godot 4.2, 2–8 Spieler, Couch-Party). Kommunikation erfolgt auf **Deutsch**. Er trifft alle kreativen Entscheidungen selbst und nutzt Agenten (Narrative Director, Writer, etc.) als ausführende Spezialisten.

**Präferenzen:**
- Extrem detaillierte, konkrete, testbare Spezifikationen — "kein Hand-waving", keine Platzhalter.
- Kein Code in Design-Dokumenten (nur Spezifikation in Prosa; API-/Methodennamen als Referenz ok).
- Alle Design-Dokumente folgen dem 8-Sektionen-Standard (Overview, Player Fantasy, Detailed Rules, Formulas, Edge Cases, Dependencies, Tuning Knobs, Acceptance Criteria).
- Deutsche Fachbegriffe; Legacy-STP-Begriffe (Cookie, Cake, Sara, Nolok, GNU) sind verboten (Rebranding).
